# Frontend Design

这是一个面向课堂教学场景的前端设计技能，用于指导 HTML/CSS/JavaScript 的学习与实践。

## 适用场景

- 课堂示例代码的编写与讲解
- 学生作业的指导与评审
- 前端基础概念的演示
- 小型网页项目的快速搭建

## 核心原则

### 1. 语义化 HTML
- 使用合适的标签（`<header>`、`<nav>`、`<main>`、`<section>`、`<article>`、`<footer>`）
- 表单元素要有对应的 `<label>`
- 图片必须有 `alt` 属性

### 2. 渐进增强
- 先保证内容可用，再添加样式和交互
- 不依赖 JavaScript 才能浏览核心内容

### 3. 响应式设计
- 使用百分比、`em`/`rem`、`vh`/`vw` 等相对单位
- 媒体查询覆盖常见断点（320px、768px、1024px、1440px）
- 移动端优先

### 4. 可访问性（A11y）
- 颜色对比度至少 4.5:1
- 键盘可操作（`:focus` 样式不要移除）
- ARIA 属性只在必要时使用

## 课堂工作流

### 讲解新概念
1. 用一句话说清"是什么"和"为什么"
2. 给出最小可运行示例（10 行以内）
3. 展示常见变体和边界情况
4. 布置小练习

### 作业指导
1. 明确验收标准
2. 提供 starter code 或项目骨架
3. 标注难度级别（⭐/⭐⭐/⭐⭐⭐）
4. 给出扩展方向供学有余力的同学

### 代码规范
- HTML：双引号、属性排序（class → id → data-* → src/href → 其他）
- CSS：属性按功能分组（布局 → 盒模型 → 文字 → 视觉）
- JS：`const`/`let` 优先、分号、单引号、2 空格缩进

## 常用资源

- MDN Web Docs（权威参考）
- CSS-Tricks（实用技巧）
- Can I Use（兼容性查询）

## 反模式提醒

- 不要用 `<table>` 做页面布局
- 不要用 `!important` 覆盖样式（除非迫不得已）
- 不要在 HTML 里写内联事件处理（`onclick="..."`）
- 不要忽略浏览器默认样式直接写 CSS reset，先用 normalize.css
