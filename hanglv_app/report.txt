var ctx = canvas.getContext('2d');
var captchaCode = '';
function drawCaptcha() {
  var chars = 'ABCDEFGHJKLMNPQRSTUVWXYZabcdefghjkmnpqrstuvwxyz23456789';
  captchaCode = '';
  for (var i = 0; i < 4; i++) {
    captchaCode += chars.charAt(Math.floor(Math.random() * chars.length));
  }
  ctx.fillStyle = '#e8f9ef';
  ctx.fillRect(0, 0, 100, 40);
  for (var i = 0; i < 5; i++) {
    ctx.strokeStyle = 'rgba(34,197,94,.3)';
    ctx.beginPath();
    ctx.moveTo(Math.random()*100, Math.random()*40);
    ctx.lineTo(Math.random()*100, Math.random()*40);
    ctx.stroke();
  }
  for (var i = 0; i < 4; i++) {
    ctx.font = 'bold 20px Arial';
    ctx.fillStyle = ['#16a34a','#ef4444','#1677ff','#f59e0b'][i];
    ctx.save();
    ctx.translate(15 + i*22, 28);
    ctx.rotate((Math.random()-.5)*.4);
    ctx.fillText(captchaCode[i], 0, 0);
    ctx.restore();
  }
}

四、项目总结
本次图像解决方案选取项目底部下导航为对象，采用纯内联SVG矢量图标方案，5个Tab图标全部手写SVG path实现，无需外部图标库请求，零网络开销。

项目收获：
1. 理解了内联SVG图标"直接写在HTML中"的机制，图标颜色通过fill: currentColor自动继承CSS文字颜色，实现选中态（绿色#22c55e）与未选中态（灰色#9ca3af）变色零成本；
2. 学会从Material Design Icons风格的SVG path数据中选取并适配到自己的项目，掌握纯内联SVG这一图像解决方案；
3. 通过抽取css/cao_style.css全局样式，实现9个页面底部导航代码零重复，所有类名统一cao_前缀，符合全局CSS设计要求。

遇到的问题与教训：
1. 最初使用emoji作为图标占位，后来对照真实航旅纵横APP截图发现应该用线性SVG图标，重新设计了5个path并统一stroke/fill风格；
2. 最初底部是4个Tab，后来对照真实APP发现是5个（首页/行程/经验/动态/我），补齐了行程页和经验页；
3. SVG的fill默认是黑色，需要设置fill="currentColor"才能跟随CSS color属性变色，否则选中态切换无效。

AI使用说明：本次项目使用AI辅助完成SVG图标path设计、Canvas验证码代码编写、16张本地图片素材生成与移动端适配调试；本人负责图标选取、代码阅读、页面样式调整与全部功能测试。

心得体会：图像资源是网页设计的核心元素，采用纯内联SVG矢量图标方案可以显著减少图片请求、保证高清显示并方便换色，是移动端页面"图像解决方案"的高效实践。
