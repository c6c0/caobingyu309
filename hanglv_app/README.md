## 二、各页面对照真实APP的还原点

### 首页 `index.html`
- 顶部：搜索图标 + 探索/出行子Tab + 礼物 + 消息
- **探索**：快捷宫格（机票/火车票/打车/酒店/全球免税）、三栏服务（航班服务/本地出行/特色功能）、民航直销蓝色banner、发现目的地（特价航线tab+3张目的地卡片）
- **出行**：旅程影音读物（视频缩略图）、快捷宫格、飞行回忆统计（61.62%超越全国用户/1个国家/12枚徽章）、航线图（21986km/39h30min）、火车轨迹

### 行程 `trip.html`
- 子Tab：待出行/已结束/家人行程
- 家人行程推广页：老人小孩飞机图、3个特性（确认行程/帮值机/平安提醒）、蓝色"添加家人"按钮

### 经验 `experience.html`
- **点评榜**：3张彩色榜单卡（绿航司服务榜/蓝机场设施榜/紫航线餐食榜）、点评行程（温州龙湾4.56分/大连周水子4.58分）、推荐榜单tab、TOP1/TOP2机场列表（大兴/周水子/天山）
- **广场**：今日热议蓝色卡片（3条热议）、旅途云听、经验/讨论tab、投票贴（手机vs相机5181人投票）、双节出行讨论、国庆反向游4图帖子、差旅日记话题

### 动态 `flight_status.html`
- 子Tab：航班动态/火车动态
- 查询卡片：按航班号/按起降地/按飞机编号、航班号输入、出发日期、绿色"航班查询"大按钮
- 沙特阿拉伯广告banner
- 3个快捷入口（执飞航线/民航看板/公务机）
- 北京首都机场实时航班列表（CA994多伦多起飞、ZH9111深圳到达）
- 榜单tab（风景榜/盘旋榜/延误榜/准点榜/到达榜）

### 我的 `mine.html`
- 顶部：头像+游客+耳机/消息/扫一扫/设置
- 航旅会棕色卡片（完整飞行记录/全年航延保障/机场贵宾厅）
- "把飞过的航线剪成旅行大片"
- 订单宫格6个（待支付/处理中/售后退改/待开票/全部订单/商旅服务）
- 证件宫格6个（我的证件/联系人/常客卡/首次飞行/签证/全部）
- 钱包宫格5个（余额/礼金/付款码/银行卡/钱包）
- 韩国之旅广告banner
- 礼金中心（优酷/芒果会员）+ 票券权益（机票券15礼金/酒店券8元）

## 三、技术规范（按题目要求）

- **纯原生** HTML/CSS/JS，无 jQuery/Vue/React/Bootstrap/Tailwind
- 所有 class/id 以 `cao_` 开头（作者姓 Cao）
- 所有图片/CSS/JS/字体本地化，无外部CDN
- 图片独立目录 `images/`，文件名全英文
- 主色：**鲜绿色 #22c55e**（航旅纵横品牌色）

## 四、JS 交互效果（≥6个）

1. 探索/出行 子Tab切换
2. 广场/点评榜 子Tab切换
3. 航班号查询按钮（表单校验）
4. 回到顶部按钮
5. 目的地tab横向滚动
6. 榜单卡片hover
7. （后台）侧边栏切换 + 数字滚动动画

## 五、fetch Mock 数据（≥4处）

| 文件 | 用途 |
| --- | --- |
| `data/banners.json` | 轮播/推荐数据 |
| `data/flights.json` | 航班列表 |
