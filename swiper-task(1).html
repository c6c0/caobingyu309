cube 3D 效果：JS 没问题，为何看起来"没实现"？—— CSS overflow:hidden vs overflow:visible

cube 效果的 3D 立体需要溢出空间才能展示完整。swiper 容器默认 overflow:hidden，把立方体的侧面和阴影都裁掉了，看起来就像"cube 效果没生效"。左侧是原样 JS + 默认 CSS，右侧只改了一条 CSS，立方体立刻完整。

🐛 Bug 版 JS 配置正确，但立方体侧面被裁

JS 配置和右边完全相同（effect:'cube' + cubeEffect），只多了默认的 overflow:hidden，立方体只剩下一个平面在转。

⚠️ overflow:hidden · 立方体被裁切
/* Swiper 默认样式 */ .swiper { overflow: hidden; } // 立方体侧面被裁

✅ 修复版 加一条 overflow:visible，3D 完整

JS 配置完全相同，只给外层容器加了一条 CSS 覆盖。立方体的 6 个面 + 阴影 + 立体侧面完整呈现。

✅ overflow:visible · 立方体完整
/* 加一条覆盖就修好 */ .wy-cube-fix .wy-swiper .swiper { overflow: visible; } // 立方体完整了 🎉
// 📋 两侧 JS 配置 100% 相同 —— 对比的不是 JS，而是 CSS overflow new Swiper('#wySw5bug', { loop:true, effect:'cube', cubeEffect:{ slideShadows:true, shadow:true }, keyboard:true }); new Swiper('#wySw5fix', { loop:true, effect:'cube', cubeEffect:{ slideShadows:true, shadow:true }, keyboard:true }); // ↑ 两行一模一样，唯一区别是容器 .swiper 的 overflow 取值

🎬 creative 电影墙解析自定义 transform · 本课未讲

演示四第 7 按钮 creative 背后是 creativeEffect 配置，允许开发者完全自定义进出场幻灯片的 transform 状态。这是 Swiper 效果中最灵活、也最像"动画编排"的一个。

📖 creativeEffect 四大属性

属性类型含义示例
translate[X, Y, Z]三轴平移（px 或百分比如 '100%'）['-100%', '-50%', -200]
rotate[X, Y, Z]三轴旋转角度（度）[0, 0, -15]
opacity0 ~ 1目标透明度0（淡出）
scale0 ~ 1+缩放比例0.8（缩小）

🎬 电影墙动画逻辑（我们写的版本）

prev（离场）：向左 100% + 向上 50% + Z 后退 200px + 逆时针 15° + 缩小 + 淡出 → 海报挂到左边墙上
next（进场）：向右 100% + 向下 50% + Z 后退 200px + 顺时针 15° + 缩小 + 淡出 → 从右下角入场归位

creativeEffect: { prev: { translate: ['-100%', '-50%', -200], rotate: [0,0,-15], opacity: 0, scale: 0.8 }, next: { translate: [ '100%', '50%', -200], rotate: [0,0, 15], opacity: 0, scale: 0.8 }, } // ↑ 演示四切换 creative 时会触发这段配置
